FORMATS
- Models: FBX (binary, FBX 2020)
- Texture: PNG, 1254 x 1254
- Source scenes: .blend (Blender 4.5) and .mb (Maya)

HOW TO USE
1. Import an FBX from the Models folder into your project, or use the
   combined file to bring in everything at once.
2. Assign Textures/WBA_GradientAtlas_Halloween_v1.png as the Base Color
   texture. All assets share one material, WBA_MAT_Halloween_Atlas.
3. Models import at the world origin with their base at Y = 0. Units are
   centimeters and files are Y-up.
The source scenes reference the texture from the Textures folder. If your
software cannot find it automatically, re-link the texture from there. If
an FBX import shows a missing texture, assign the provided atlas file
manually as the Base Color texture.
